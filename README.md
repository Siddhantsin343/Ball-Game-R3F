# 🏁 Marble Race

A fun physics-based **3D marble racing game** built with **React Three Fiber (R3F)**. Control a marble through a challenging obstacle course, avoid collisions, and race against the clock to reach the finish line.

## 🎮 Gameplay

Your objective is simple:

* Roll the marble through the course.
* Avoid obstacles and barriers.
* Reach the finish line **within 20 seconds** to win.

## ✨ Features

* 🎱 Physics-based marble movement
* 🎮 Smooth keyboard controls
* 🚧 Collision detection using physics colliders
* 🛑 Obstacles that block the player's path
* 🏁 Finish line detection
* ⏱️ 20-second challenge timer
* 🌍 Interactive 3D environment
* ⚡ Built with modern React and WebGL technologies

## 🎮 Controls

| Key       | Action        |
| --------- | ------------- |
| **W / ↑** | Move Forward  |
| **S / ↓** | Move Backward |
| **A / ←** | Move Left     |
| **D / →** | Move Right    |

## 🛠️ Tech Stack

* React
* React Three Fiber (R3F)
* Drei
* Three.js
* Rapier Physics

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Siddhantsin343/Ball-Game-R3F.git


# Install dependencies
npm install

# Start the development server
npm run dev
```
